One cache slot holds one whole block. Slot = block number mod slots per core. Writes to different words in one block can still invalidate each other: false sharing.

Traffic accounting

BusRd, BusRdX, and BusUpgr count coherence requests. Writebacks count whole-block data publications separately. Hits/misses count processor reads/writes, not explicit flush commands.

Use cores, lines, words, memory, and operations. Memory is an array of 4–32 integer words, divisible by the block size. At most 200 read/write/flush operations.

States & model boundaries

M / Modified — this core owns the only valid copy; memory may be stale.

E / Exclusive — this core owns the only valid copy; memory is current.

S / Shared — clean data, possibly held by other cores.

I / Invalid — the retained tag/data cannot satisfy a read.

This is a simplified atomic snooping MESI model with direct-mapped, write-back, write-allocate caches. Modified interventions publish the block to memory before sharing or transfer. Flush changes M to E and retains the clean copy. There are no races, transient states, store buffers, speculative execution, multilevel caches, timings, or language-level memory-model guarantees.
